About

This repository maintains the code files for dynamic programming problems, solutions, approaches, notes, and examples. It is designed to be both a practical reference and an aesthetic learning guide — clear sections, gentle colors, and a simple animated hero to make the content inviting.

What this repo contains

- problems/      — categorized problem statements and links
- solutions/     — tested code snippets (with short explanations)
- approaches/    — pattern write-ups and recurrence derivations
- notes/         — high-level intuition, trade-offs, and diagrams
- examples/      — step-by-step DP table walkthroughs and visuals
- assets/        — images / SVGs used by the README

What is Dynamic Programming? (short)

Dynamic Programming (DP) is a technique that solves complex problems by breaking them into overlapping subproblems, solving each subproblem once, and reusing those solutions.

Core ideas:
- Overlapping subproblems
- Optimal substructure
- Two common styles: top-down (memoization) and bottom-up (tabulation)

How to use this repo (visual path)

Pick a topic → Read approach → Study solution → Run examples → Implement variations

Representation and effects

- The hero image (above) uses an animated SVG to show subtle motion and gradient colors.
- Sections use clear headings, short paragraphs, and monospace templates for code logic.
- The README intentionally balances modern minimalism with classic structure.

Practice path (beginner → advanced)

1. Foundation: Fibonacci (memo), basic knapsack, coin change
2. Convert & compare: Top-down → Bottom-up
3. State recognition: LIS, LCS, partition, edit distance
4. Optimize: Space-optimized DP, rolling arrays
5. Specialized: Bitmask DP, Tree DP, Digit DP

Patterns & quick tips

- Identify minimal state variables
- Write the recurrence before coding
- Prefer clarity first, then optimize
- Draw the DP table to visualize transitions

Motivational lines

- "Small steps + repeated practice = mastery."  
- "Every DP problem is a puzzle: break it down, trust the recurrence, keep building."  
- "Learn the patterns, not just the answers — progress compounds."
